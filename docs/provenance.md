# Provenance

BillTrace is an original portfolio implementation. No reference-project source files were cloned into this repository. Public billing and operations examples informed the choice of problem; the data model, transaction boundaries, endpoints, tests and documentation were implemented for this project.

Some Git commit timestamps were deliberately selected as historical metadata. They do not establish when the implementation was written, tested or delivered. Dependency versions, GitHub creation events and CI run timestamps retain their own chronology. This repository does not claim historical production use or independent human authorship of AI-assisted work.

Third-party dependencies retain their respective licenses. The project MIT license covers this repository's original source.
